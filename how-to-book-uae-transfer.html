BOOKING QUESTIONS

Before you send your request.

What details are needed for an airport transfer quote?

Send the airport, terminal, flight number, date, time, pickup or destination, passengers, luggage and any return journey.

What details are needed for a chauffeur quote?

Send the date, start time, pickup, planned stops, expected duration, passengers and luggage.

How is the vehicle category determined?

Vehicle requirements depend on passengers, luggage, journey type and availability. Share accurate figures so a suitable category can be proposed.

Does sending a request confirm the booking?

No. A request starts the quotation process. The journey is confirmed only after Ciao Mobility confirms the service details.

Can I request a return journey?

Yes. Include the return date, pickup time and route so both directions can be reviewed together.
